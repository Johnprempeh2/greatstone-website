# Link audit: what an engagement actually needs to click

11 Sep 2026. Built by simulation: ten practitioner agents each living in one surface of the
portal walking real engagement moments, three end to end journey critics (the session cycle,
the build case, the evidence trail), then an adversarial verification of every candidate
against the live code. 47 journeys walked, 99 candidates, 96 survived, ranked must / should.

The rule each link had to pass: a simulated task reached for it and fell back to the tab bar.
The counter rule: link everything is a disease, one good way in beats a page of blue text.
