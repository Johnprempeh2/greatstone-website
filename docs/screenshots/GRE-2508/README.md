# Two Doors tools carousel and editor blocks

The before images use `origin/main`; the after images use this branch. Both were captured from `npm run dev` at 1440 px and 390 px. The page content is unchanged. The after build adds native horizontal trackpad and touch scrolling and separate tools, conversation, and choice blocks in the editor.

| Width | Before | After |
| --- | --- | --- |
| 1440 px | [Desktop before](before-desktop.png) | [Desktop after](after-desktop.png) |
| 390 px | [Phone before](before-phone.png) | [Phone after](after-phone.png) |

Browser interaction check at 1440 px: a horizontal wheel gesture moved the tools carousel from 0 to 430 px; the next button moved it to 878 px. No page draft or public page was published.
